# Open account launch

This standalone private runtime supports open signup after the existing OIDC code/PKCE/state/nonce/JWKS verification. The exact issuer and opaque subject resolve the existing active private owner, or atomically create one new owner in the separate operational graph. No invitation or additional email_verified flag is required. Authenticated email is display information in this slice; legacy same-email reconciliation belongs to the separate migration lane and never transfers another owner’s data implicitly.

Upload has one disclosure/action covering private retention and bounded OpenAI processing. Complete ZIP or Connections-only ZIP/CSV is accepted up to 64 MiB, with 8 MiB per selected CSV, 40 MiB selected expansion, 2,000 entries and 100,000 parser records. Only Connections/Profile/Positions/Education/Skills CSV members are inflated; all other original bytes remain recoverable in the privately retained ZIP with an immutable manifest. Publication uses the existing bounded chunks and one final fence; no first-N truncation. One process-wide upload at a time bounds memory, with a 1 GiB runtime cap and 65 MiB multipart ingress cap.

Returning users rediscover current published imports in their owner scope. My network and the account MCP tool search all current owner imports, bounded to 1,000 imports/100,000 observations; an exceeded bound fails explicitly. Source IDs and archive provenance remain unchanged. Connection observations are not deduplicated into shared people or asserted to be second-degree edges. Every search rechecks complete live publication state after model completion.

Settings issues a private account search-only bearer for current and future imports until revoked. Audience `unlinked-account-tools-v1`, tool `unlinked_search_network`, no raw assets, no global graph access, no owner parameter. The grant and revocation persist in owner-private operational resources; the domain-separated signing key derives from the approved private graph secret, so unchanged secrets preserve grants across restarts. Replacing that secret revokes every old account grant. Browser sessions remain 15 minutes. Copying MCP setup is configuration, not proof that a client connected; a successful authenticated real MCP call is the connection acceptance receipt.

The source tests explicitly distinguish synthetic identity/Map persistence from production callback/Noos/model evidence. Live friends' archives remain gated on the exact deployed OIDC callback, actual browser synthetic Connections-only/full-ZIP upload, complete counts, real model, MCP/revocation and recovery acceptance.
